# 1.4 相比之前加了什么

> 对比区间：**1.1.0（首发）→ 1.4.1（当前 latest）**
> 中间发过的版本：1.1.0 / 1.1.1 / 1.2.0 / 1.4.0 / 1.4.1

---

## 一句话

**1.1 是一颗能记住事的脑；1.4 是一颗会说"我委屈"、会真的去开 App、口味会被人设带着走的脑。**

---

## 一、情绪：从"三个数字"到"会说人话"

| | 1.1.0 | 1.4.1 |
|---|---|---|
| 情绪表示 | PAD 三个数字（-1~1） | PAD 三维 **+ 情绪词表** |
| 能不能说出"委屈" | ❌ 说不出，只有数值 | ✅ 词表 ≥10 个时能命名 |
| 学习情绪词 | ❌ | ✅ 要**两个来源一致**才采纳（问用户 / 抖音 / 群聊） |
| 自己归纳定义 | ❌ | ✅ 同词攒够 3 个实例 → 自己总结"委屈是被污蔑" |
| 匹配不上时 | 硬给个最近的 | ✅ 说"说不清，有点像 A，又像 B" |

**三段式**：`只会说"不知道"` → `能说"我有点委屈"` → `能说"这是被污蔑，我委屈"`。

而且**同一件事，不同状态不同结果**：

```
被冤枉 + 有劲 → 掌控感高 → 生气 → "凭什么"
被冤枉 + 累了 → 掌控感低 → 委屈 → "……算了"
```

## 二、记忆：从"只有经历"到"有卡片、有平台"

| | 1.1.0 | 1.4.1 |
|---|---|---|
| 情景记忆 | ✅ 30 天 TTL | ✅ 不变 |
| 印象 / 事实 / 口味 | ✅ | ✅ 不变 |
| **记忆卡片** | ❌ 长对话只能靠预算硬截 | ✅ 超 6000 字压成 ≤160 字卡片，卡片也吃 TTL |
| **平台记忆** | ❌ 只有"跟谁聊过"，没有"刷过什么" | ✅ QQ / 微信 / 抖音 / B站 各一桶 |
| 跨平台检索 | ❌ | ✅ "这事我见过"——跨平台找相似标题 |
| 备份 | ❌ 单文件坏 = 丢档 | ✅ 自动 `.bak`，读失败自修复 |

平台记忆每桶记四样：**看过哪些（带反应和时长）、口味、上次停在哪、一共待了多久**。

| | 1.1.0 | 1.4.1 |
|---|---|---|
| 三种身体 | ✅ 手机 / 平板 / 电脑 | ✅ 不变 |

## 四、口味：从"刷出来"到"人设带着走"

这是 1.4 最大的一块。

| | 1.1.0 | 1.4.1 |
|---|---|---|
| 口味来源 | ❌ 没有口味概念 | ✅ **先验（人设算）70% + 经历 30%** |
| 选 App | ❌ | ✅ `pickApp()`——社交型摸 QQ，学霸型摸 B站 |
| 选内容 | ❌ | ✅ `pickContent()`——懒鱼选解压，好奇选科技 |
| 人设会不会被刷改变 | ❌ | ✅ **会**：看 120 条解压，`懒` 从 0.50 → 0.98 |

**闭环**：

```
用户写的卡 → 决定先看什么 → 刷 → 有反应 → 改人设 → 口味变 → 刷的不一样
```

实测：刷 120 条解压视频后，选解压的概率 **47% → 57%**。

而且修了一个设计错误：**"谁爱看什么"和"看了会变成什么"必须是两张表**——混用的话，看解压视频会让她变理性。

## 五、人设：从"只能出生一次"到"能换卡、能转折"

| | 1.1.0 | 1.4.1 |
|---|---|---|
| 从卡出生 | ✅ | ✅ |
| **换卡** | ❌ 只能 rebirth（清空一切） | ✅ `importRoleCard()`——**只换人格，记忆/关系/身体全留** |
| 人格主档 | ❌ 说不清谁是主档 | ✅ `persona.source` 记来源+哈希+时间，**brain.json 是唯一主档** |
| **重大转折** | ❌ 只能 ±0.01，永远磨 | ✅ `reframe()`——一次推多条，幅度 1~5，**必须带证据** |
| 特质精度 | 自动统计，抽不准没法救 | ✅ 卡里写 `性格：嘴硬=0.9` 手写覆盖 + `traits.json` 旁挂 |

## 十、没变的（免得被误会）

- 人设卡**永远由用户写**，包不生成、不代写
- 拦截永远只有两条：C1 人设红线 + SAFETY
- 身份和关系永不遗忘，性格可以蜕皮
- 内核不生成对话，只负责"她是谁"
